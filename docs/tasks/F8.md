No raw public serializer that pretends to know whether an arbitrary snapshot has a live battle.

All versions exact; reject unknown versions/fields/corrupt JSON. Adapter remains an out-of-band synchronous runtime dependency, never serialized.

No functions, handles, active checkpoint, latest receipt/fault, controller revision or runtime generation saved. nextCommandId is the necessary bounded command sequence; restore keeps max(current,saved), avoiding ID reuse within this controller. Exact serialize/restore/serialize stability applies when current sequence is not ahead; rollback may retain the higher command counter intentionally.
